# Recall AI - Design System

## Design Philosophy

Professional, clean, modern SaaS dashboard.

Focus on clarity over decoration.

---

## Theme

Primary Theme:
- White
- Light Gray
- Blue Accent

Status Colors:
- Green = Success
- Amber = Warning
- Red = Error

---

## Border Radius

Cards:
- Rounded Large

Buttons:
- Rounded Medium

Inputs:
- Rounded Medium

---

## Shadows

Soft shadows only.

Avoid heavy shadows.

---

## Typography

Heading

- Large
- Bold

Subheading

- Medium
- Muted

Body

- Normal

Labels

- Small
- Semi Bold

---

## Spacing

Consistent spacing throughout the application.

Large white spaces preferred over crowded layouts.

---

## Icons

Library:
Lucide React

Only outline icons.

---

## Components

- Sidebar
- Header
- Cards
- Tables
- Buttons
- Inputs
- Search Bar
- Badges
- Dialogs
- Toasts

Every page must reuse these components.
